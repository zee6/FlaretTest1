# Football 1 for iPhone

Native SwiftUI interface prototype for the Football 1 research product.

## Open in Xcode

Open:

`ios/Football1Mobile/Football1Mobile.xcodeproj`

Choose the **Football1Mobile** scheme and an iPhone simulator (or your connected iPhone), then press **Command-R**.

The iPhone UI is intentionally preview-labelled. It does not call bookmaker APIs and does not contain a language-model dependency. It is designed so the later Python-generated prospective JSON bridge can replace the preview values without moving model logic into Swift.

Bundle identifier: `com.riskbrain.Football1Mobile`

Minimum iOS: 17.0
